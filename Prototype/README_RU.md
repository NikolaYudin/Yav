# ЯВЬ: Забытые Былины — Windows-тест сбор YavLaunch.exe

## Что это
Небольшой **640×480** exe-файл для быстрой проверки на Windows 10/11 того,
что уже заложено в Unity-проект (`Assets/Scripts`): цикл экранов
**Запуск → Выбор героя (Богатырь / Стрелок / Волхв) → Подтверждение**,
параметры классов и файловая «база данных» прогресса.

Это не финальная графика игры — это smoke-тест UI-цикла и данных, чтобы
двигаться дальше по архитектуре, пока Unity-сцены собираются параллельно.

## Как запустить
1. Распакуйте архив в любую папку (например `C:\Yav\`).
2. Дважды кликните `YavLaunch.exe`.
   - Если Windows покажет окно Smart Screen («неизвестный издатель») —
     нажмите **«Подробнее» → «Выполнить в любом случае»**. Файл собран
     открытым компилятором mingw-w64, без подписи.
3. Окно фиксированное, 640×480, ресайз выключен.

## Управление
| Экран            | Действие                                                        |
|------------------|-----------------------------------------------------------------|
| Запуск           | «НАЧАТЬ ИГРУ» → выбор героя; «ПРЕДАНИЕ» → легенда; «ВЫХОД»      |
| Выбор героя      | Клик по карточке = выбрать; поле «Имя героя»; «ВЫБРАТЬ ГЕРОЯ»   |
| Подтверждение    | «Назад» — вернуться на стартовый экран                          |

## Файловая БД
После нажатия «ВЫБРАТЬ ГЕРОЯ» рядом с exe создаётся файл
`YavLaunch_profile.json`:

```json
{
  "nickname": "Иван",
  "classId": 0,
  "classRu": "Богатырь"
}
```

Формат совпадает с идеологией `IRepository<T>` из Unity-проекта: позже
этот слой меняется на серверную БД (PostgreSQL/Firebase), а формат записи
остаётся тем же.

## Синхронизация с Unity-проектом
Числа характеристик в exe — зеркало
`Assets/Scripts/Core/CharacterClass.cs` (`Yav.Core.CharacterClassDef.All`):

| Класс    | HP  | DMG | Мана | Лут+ | Роль                  |

| Богатырь | 150 | 18  | 60   | +50  | Танк / ближний бой    |
| Стрелок  | 100 | 24  | 80   | +20  | Дальний физический урон|
| Волхв    | 80  | 30  | 160  | +0   | Магия / поддержка     |

## Пересборка из исходников (Linux/macOS/WSL)
```bash
sudo apt-get install gcc-mingw-w64-x86-64   # один раз
bash Prototype/build.sh                     # -> Prototype/YavLaunch.exe
```
Русский текст в `yav_prototype.c` представлен ASCII escape-последовательностями
(UTF-16 code units), поэтому проблем с кодировкой при сборке нет.
Генератор текста и таблиц: `Prototype/gen.py`.

## Известные ограничения прототипа
- Нет анимаций/звуков — только статичная отрисовка GDI.
- Сети ещё нет: выбор проверяется локально (в финальной версии — сервер).
- Шрифт заголовка Georgia отсутствует на редких системах — тогда используется запасной.
