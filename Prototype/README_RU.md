# ЯВЬ: Забытые Былины — тестовый прототип v0.5 (Windows)

Просто замените папку с прошлым тестом этой и запустите YavLaunch.exe.

## Как запустить
1. Распакуйте архив в любую папку.
2. Запустите `YavLaunch.exe` (Windows 10/11, 64-bit, без установки).
3. Если SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Что нового в v0.5
- Создание героя: только ввод имени. Вы начинаете **молодцем** (без класса).
- После 3 поручений Кота Учёного открывается экран выбора стези: **Воин / Лучник / Волхв**.
- Интерфейс мира:
  - левый верхний угол — панель: имя, уровень, полосы здоровья (Ж) и энергии/маны (Э);
  - по центру сверху — окно фокуса (кто/что под курсором внимания: NPC или предмет);
  - справа по центру — окно диалога с говорящим;
  - снизу по центру — бар быстрых умений (клавиши 1–4);
  - инвентарь — кнопка/клавиша Tab слева, предметы надеваются двойным кликом мыши (или клавишей I — выпить зелье). Надетые вещи отмечены в слотах экипировки.

## Прохождение (демо-цикл)
1. Введите имя героя → «Понятно» → мир деревни.
2. Подойдите к Коту Учёному (клик мышью куда идти, или WASD), нажмите E — приветствие и задание №1: собрать 3 жёлудя под дубом (E рядом с жёлудем).
3. Задание №2: отнесите руду Кузнецу Терентию (E у кузницы) — он выкует все три оружия: булаву, лук и посох (+оберег).
4. Задание №3: отнесите полотна Марье Искуснице (E у её избы) — она сошьёт одеяния: тяжёлый доспех, лёгкий доспех и мантию.
5. Выполните все 3 поручения → Кот предложит выбрать стезь: Воин, Лучник или Волхв (клик по карточке или клавиши 1/2/3).
6. Откройте инвентарь (Tab), двойным кликом наденьте оружие и одеяние — характеристики вырастут, надетое видно в слотах.

## Управление
- Движение: ЛКМ — кликнули в точку, герой идёт туда (обходит избы, колодец, дуб). WASD — ручное управление.
- E — взаимодействие (говорить с NPC, подобрать жёлудь).
- 1–4 — умения быстрого доступа (энергия восстанавливается сама).
- Tab — инвентарь открыть/закрыть; двойной клик по предмету — надеть/снять (зелье — выпить).
- Esc — закрыть диалог/инвентарь, затем выход в меню.

## Сохранение
Профиль пишется в реальном времени атомарно в `YavLaunch_profile.json` рядом с exe.
Если файл найден при запуске — предлагается «Продолжить игру» с вашим прогрессом.

Это UI/логический прототип для проверки цикла и данных; вся игровая логика в проекте спроектирована server-authoritative (проверки на сервере), сохранение — через интерфейс репозитория (файловая БД → позже PostgreSQL/Firebase).
