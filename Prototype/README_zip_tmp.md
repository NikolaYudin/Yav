# ЯВЬ: Забытые Былины — тестовый прототип v0.8 (Windows)

**Запуск:** распакуйте архив `Yav_Win_Test.zip` в любую папку → `YavLaunch.exe`.
Если SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
Прогресс сохраняется автоматически в реальном времени в `YavLaunch_profile.json` рядом с exe.

## Что нового в v0.8 (исправления после вашего теста)
1. **Исправлен вылет после ввода имени** — добавлен перехват ошибок (если что-то пойдёт не так,
   игра больше не закрывается молча: покажет окно с предложением продолжить и запишет
   `YavLaunch_error.log` рядом с exe). Поле ввода имени теперь получает фокус сразу,
   пробелы в начале/конце имени обрезаются, пустое имя не приводит к сбою.
2. **Миграция старых сохранений** — профили, сохранённые сборкой v0.7 на середине квеста,
   теперь при входе в мир дозаполняются (руда/полотно выдаются по ходу задания),
   ничего не «залипает». Жёлуди под дубом появляются сразу после приветствия кота.
3. **Разрешение 1024×768 доведено до ума** — после смены размера все элементы интерфейса
   перестроены под широкий экран: меню по центру, карточки выбора стези по центру,
   текст диалогов переносится по словам и не выходит за границы панелей.
4. Из v0.7 сохранено: всплывающие уведомления о выполнении поручений (5 сек),
   кнопка «Сбор» ресурсов в баре умений, ресурсы от кота сразу после сдачи желудей.

## Как пройти демо-цикл
1. Введите имя героя → «НАЧАТЬ ПУТЬ» (вы начинаете **молодцем**, без класса).
2. Кот Учёный даст первое поручение: собрать 3 жёлудя под дубом (клик мышью — идти,
   E или клик по жёлудю — подобрать; кнопка «Сбор» в баре — клавиша 4).
3. Сдайте жёлуди коту → он выдаст руду и полотно.
4. Кузнец Терентий (изба слева) — отдайте руду, выберите булаву/лук/посох.
5. Марья Искусница (изба справа) — отдайте полотно, выберите доспех/кожанку/мантию.
6. Предметы во вкладке инвентаря (Tab) экипируются кликом; надетое подсвечено.
7. После трёх поручений откроется выбор стези: Воин / Лучник / Волхв (карточки или 1/2/3).

## Управление
| Клавиша | Действие |
|---|---|
| ЛКМ | идти к точке / выбрать предмет / говорить |
| E | взаимодействие (NPC, жёлуди, стойка припасов) |
| 1–5 | умения из бара (Удар, классовое, помощь, Сбор, Зорю) |
| Tab | инвентарь |
| Esc | закрыть диалог/инвентарь, вернуться в меню |

Архивы предыдущих сборок — в папке `build_archives/` (v0.2, v0.5, v0.6, v0.7).
