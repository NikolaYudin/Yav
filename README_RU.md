# ЯВЬ: Забытые Былины — тестовый прототип v0.9 (Windows)

**Запуск:** распакуйте архив `Yav_Win_Test.zip` в любую папку → `YavLaunch.exe`.
Если SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
Прогресс сохраняется автоматически в реальном времени в `YavLaunch_profile.json` рядом с exe.

## Что нового в v0.9 (исправления после вашего теста)
1. **Убран бесконечный цикл ошибок** — раньше при сбое кнопка «Да» повторяла ту же
   инструкцию и ошибка появлялась снова и снова. Теперь повторных попыток максимум две,
   после чего программа корректно завершается. Все сбои пишутся в `YavLaunch_error.log`
   (с кодом ошибки и адресом) — если увидите это окно, пришлите файл мне.
2. **Исправлен вход через Enter** — теперь Enter прямо в поле имени = нажатие кнопки
   «НАЧАТЬ ПУТЬ» (раньше Enter ничего не делал, а с основного меню мог вернуть на этот
   же экран). На экранах меню Enter активирует главную кнопку.
3. **Длина имени ограничена** (24 символа), лишние пробелы по краям обрезаются —
   профиль больше не может «сломаться» на длинном имени.
4. **Жёлуди: живая обратная связь** — при подборе каждого показывается счётчик
   «Желудь: N/3», при сборе трёх — всплывающее уведомление о выполнении поручения.
5. Из v0.8 сохранено: окно 1024×768, центрированные меню/карточки стези, перенос
   текста диалогов, миграция старых сохранений, ресурсы от кота сразу после желудей.

## Как пройти демо-цикл
1. Введите имя героя → Enter или «НАЧАТЬ ПУТЬ» (вы начинаете **молодцем**, без класса).
2. Кот Учёный даст первое поручение: собрать 3 жёлудя под дубом (клик мышью — идти,
   E или клик по жёлудю — подобрать; кнопка «Сбор» в баре — клавиша 4).
3. Сдайте жёлуди коту → он выдаст руду и полотно.
4. Кузнец Терентий (изба слева) — отдайте руду, выберите булаву/лук/посох.
5. Марья Искусница (изба справа) — отдайте полотно, выберите доспех/кожанку/мантию.
6. Предметы во вкладке инвентаря (Tab) экипируются кликом; надетое подсвечено.
7. После трёх поручений откроется выбор стези: Воин / Лучник / Волхв (карточки или 1/2/3).

## Управление
| Клавиша | Действие |
|---|---|
| ЛКМ | идти к точке / выбрать предмет / говорить |
| E | взаимодействие (NPC, жёлуди, стойка припасов) |
| 1–5 | умения из бара (Удар, классовое, помощь, Сбор, Зорю) |
| Tab | инвентарь |
| Enter | подтвердить (имя героя / главная кнопка меню) |
| Esc | закрыть диалог/инвентарь, вернуться в меню |

Архивы предыдущих сборок — в папке `build_archives/` (v0.2, v0.5, v0.6, v0.7, v0.8).
