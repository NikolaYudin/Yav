# ЯВЬ: Забытые Былины — тестовый прототип v0.16 (Windows)

**Запуск:** распакуйте архив `Yav_Win_Test.zip` в любую папку → `YavLaunch.exe`.
Если SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
Прогресс сохраняется автоматически в реальном времени в `YavLaunch_profile.json` рядом с exe.

## Что нового в v0.16 (сетка движения + иконки и подсказки предметов)
1. **Сетка движения.** В мире поверх травы отрисована шаговая сетка (клетка 32 px).
   Движение мышью теперь **только по прямой**: клик ЛКМ привязывается к ближайшей оси
   (горизонталь или вертикаль), герой идёт строго по линии, как по клеткам.
2. **Траектория.** До клика курсор показывает прицел на ближайшем пересечении линий
   сетки; после клика рисуется пунктирная траектория с маркером цели
   (жёлтая = проходима, красная = упрётся в препятствие).
3. **Иконки предметов.** В инвентаре вместо цветных квадратов — рисованные иконки:
   жёлудь с шапочкой, кристалл руды, рулон полотна, флакон зелья, оберег на цепи,
   булава / лук с тетивой / посох с набалдашником, доспехи и мантия.
4. **Подсказки при наведении.** Наведите курсор на предмет в сумке — всплывает подсказка:
   что это и что с ним делать («Руда — отнести Кузнецу Терентию», «клик: надеть/снять»,
   «двойной клик — выпить (+30 Ж)» и т.п.).

## Сохранено из прежних версий
- Окно 1024×768; создание героя — только ввод имени (вы начинаете молодцем);
- полный квест-цикл: жёлуди под дубом → Кот Учёный выдаёт руду и полотно сразу →
  Кузнец Терентий (булава/лук/посох) → Марья Искусница (доспех/мантия) →
  выбор стези Воин/Лучник/Волхв (клик или клавиши 1/2/3);
- всплывающие уведомления о выполнении поручений (5 сек);
- панель героя слева сверху (имя, уровень, HP, мана), фокус-окно сверху по центру,
  диалог справа с переносом текста, бар умений снизу по центру (клавиши 1–4,
  включая кнопку сбора ресурсов);
- инвентарь (Tab): экипировка кликом/двойным кликом, отображение надетого;
- стабильность v0.12–v0.15: устранены вылеты 0xC0000005 (безопасный формат строк,
  лимит повторов ошибки, лог `YavLaunch_error.log`).

## Управление
| Клавиша / действие | Что делает |
|---|---|
| ЛКМ по земле | Идти по прямой к точке (привязка к оси, видна траектория) |
| E | Говорить с NPC / подобрать жёлудь / собрать ресурс |
| 1–4 (или клик по баре) | Умения, слот 4 — сбор ресурсов |
| Tab | Инвентарь (клик по предмету — надеть/снять, зелье — выпить) |
| Наведение мыши на предмет | Подсказка о предмете |
| Esc | Закрыть диалог → закрыть сумку → выйти в меню |
| Enter | Подтвердить на экранах меню |
