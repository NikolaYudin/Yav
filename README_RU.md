# ЯВЬ: Забытые Былины — тестовый прототип v0.10 (Windows)

**Запуск:** распакуйте архив `Yav_Win_Test.zip` в любую папку → `YavLaunch.exe`.
Если SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
Прогресс сохраняется автоматически в реальном времени в `YavLaunch_profile.json` рядом с exe.

## Что нового в v0.10 (исправление вылета 0xC0000005)
1. **Найдена и устранена причина вашего краша.** В v0.9 функция показа диалога стала
   одиночно-аргументной, но часть мест кода продолжала передавать ей дополнительные
   аргументы (название предмета, бонус, очки лечения). При экипировке/снятии вещи или
   подборе предметов в сумку форматная строка обрабатывалась неверно — отсюда
   `0xC0000005` по одному и тому же адресу сразу после входа в мир. Теперь все такие
   места форматируют текст заранее в безопасный локальный буфер (функция `DialogFmt`).
2. **Убраны конфликтующие объявления** функции диалога (старый вариативный прототип
   остался в коде с v0.4 и переопределял поведение на сборках без проверок).
3. Ошибочные вызовы с лишними аргументами исправлены: полный рюкзак, снятие/надевание
   экипировки, питье зелья из сумки.
4. Из v0.9 сохранено: окно 1024×768, лимит повторов ошибки (макс. 2 попытки «Да»,
   затем корректное закрытие), запис всех сбоев в `YavLaunch_error.log`, Enter =
   подтвердить имя, счётчик «Желудь: N/3», всплывающие уведомления о квестах (5 сек),
   ресурсы от кота сразу после сдачи желудей, выбор стези после трёх поручений.

### Если ошибка всё же появится
Пришлите файл `YavLaunch_error.log` из папки с exe — в нём код и адрес сбоя, этого
достаточно, чтобы найти проблему точно.

## Как пройти демо-цикл
1. Введите имя героя → Enter или «НАЧАТЬ ПУТЬ» (вы начинаете **молодцем**, без класса).
2. Кот Учёный даст первое поручение: собрать 3 жёлудя под дубом (клик мышью — идти,
   E или клик по жёлудю — подобрать; кнопка «Сбор» в баре — клавиша 4).
3. Сдайте жёлуди коту → он выдаст руду и полотно.
4. Кузнец Терентий (изба слева) — отдайте руду, выберите булаву/лук/посох.
5. Марья Искусница (изба справа) — отдайте полотно, выберите доспех/кожанку/мантию.
6. Предметы во вкладке инвентаря (Tab) экипируются кликом; надетое подсвечено.
7. После трёх поручений откроется выбор стези: Воин / Лучник / Волхв (карточки или 1/2/3).

## Управление
| Клавиша | Действие |
|---|---|
| ЛКМ | идти к точке / выбрать предмет / говорить |
| E | взаимодействие (NPC, жёлуди, стойка припасов) |
| 1–5 | умения из бара (Удар, классовое, помощь, Сбор, Зорю) |
| Tab | инвентарь |
| Enter | подтвердить (имя героя / главная кнопка меню) |
| Esc | закрыть диалог/инвентарь, вернуться в меню |

Архивы предыдущих сборок — в папке `build_archives/` (v0.2, v0.5, v0.6, v0.7, v0.8).
