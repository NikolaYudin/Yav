# ЯВЬ: Забытые Былины — тестовый прототип v0.7 (Windows)

**Запуск:** распакуйте архив `Yav_Win_Test.zip` в любую папку → `YavLaunch.exe`.
Если SmartScreen предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
Прогресс сохраняется автоматически в реальном времени в `YavLaunch_profile.json` рядом с exe.

## Что нового в v0.7
1. **Разрешение окна 1024×768** — деревня перестроена под большой экран, интерфейс стал мельче и читаемее.
2. **Кот выдаёт ресурсы сразу** — после сдачи 3 желудей вы тут же получаете руду и полотно (раньше квест вставал: нести мастерам было нечего).
3. **Всплывающее уведомление о выполнении квеста** — зелёная плашка ✦ на 5 секунд по центру сверху («Поручение 1 выполнено!» и т.д.).
4. **Текст диалога больше не выходит за границы** — длинные реплики переносятся по словам внутри рамки справа.
5. Ресурсы можно добывать и в Тёмной роще (стойка с припасами справа внизу) — кнопка «Сбор» в баре (клавиша 4) или подойти и E.

## Интерфейс
- **Слева сверху** — панель героя: имя, уровень, здоровье (красная), мана (синяя).
- **Сверху по центру** — окно фокуса: на ком/чём сейчас наведён герой (NPC, предмет).
- **Справа** — окно диалога с тем, кто вас «видит».
- **Снизу по центру** — бар умений на клавиши 1–4 (класс зависит от выбранной стези), слот 4 — сбор ресурсов.
- **Tab** — инвентарь; клик по предмету — надеть/выпить; надетое помечено ✓.

## Управление
| Клавиша / мышь | Действие |
|---|---|
| ЛКМ по земле | Идти к точке клика |
| ЛКМ по желудю рядом | Поднять мгновенно |
| E | Говорить с NPC / подобрать / сдать предмет |
| 1–4 (или клик по баре) | Умения: удар, спец, лечение/бафф, **сбор ресурсов** |
| Tab | Сумка; клик по предмету — надеть/выпить (надетое помечено ✓) |
| I | Выпить зелье |
| Esc | Закрыть диалог / сумку / выйти в меню |

## Прохождение демо-цикла
1. Введите имя героя (вы начинаете **молодцем**, выбор класса на старте убран).
2. Поговорите с **Котом Учёным** у дуба → поручение 1: собрать 3 жёлудя.
3. Сдайте жёлуди коту → он даст **руду и полотно** + укажет, где добывать ещё (Тёмная роща).
4. Кузнец Терентий (изба слева) — за руду даст оружие (булава/лук/посох).
5. Марья Искусница (изба справа) — за полотно даст одеяние (доспех/кожанка/мантия).
6. Вернитесь к коту → **выберите стезю**: Воин / Лучник / Волхв (клик по карточке или 1/2/3).

## Структура проекта
```
/                      — корень репозитория
├── README_RU.md       — этот файл (единый, всегда в корне)
├── Yav_Win_Test.zip   — ТЕКУЩАЯ сборка для тестирования на Windows
├── build_archives/    — архивы предыдущих версий (с пометкой _old)
├── Prototype/         — исходники C-прототипа (WinAPI) + скрипт сборки
│   ├── yav_game.c     — весь код игры
│   ├── strings_gen.h  — строковые ресурсы (генерируются gen.py)
│   ├── shims/         — заглушки заголовков для кросс-сборки
│   └── build_game.sh  — сборка exe (mingw-w64)
├── Assets/            — Unity-скрипты (C#): запуск, выбор героя, файловая БД
└── ProjectSettings/   — настройки Unity-проекта
```

## Сборка прототипа самостоятельно
Требуется mingw-w64: `apt-get install gcc-mingw-w64-x86-64`, затем
`bash Prototype/build_game.sh` → `Prototype/YavLaunch.exe`.
