# ЯВЬ: Забытые Былины — тестовый прототип v0.22 (Windows)

## Что нового в v0.22 (жёлуди для второго окна + отдельные сохранения)
- ИСПРАВЛЕНО: при запуске двух окон жёлуди не появлялись ни у одного игрока.
  Причина: оба окна делили один файл профиля, и второе окно перезаписывало
  состояние дуба флагами первого. Теперь:
  1) каждое окно игры получает СВОЙ файл сохранения (YavLaunch_profile.json,
     YavLaunch_profile.2.json, .3.json ...) — как разные аккаунты на сервере;
  2) если мир всё же «чужой» (флаги сборов не совпадают с сумкой), дуб
     мгновенно пополняется — жёлуди видны сразу после взятия задания у кота.
- Прогнаны юнит-тесты логики респавна (7 сценариев, включая два клиента).
- LAN co-op (видимость другого героя) работает как раньше.

## Что нового в v0.21 (иконки квестов над NPC + полные карточки стезей)
- **Иконка разговора над головой NPC**: золотой «пузырь» с пёрышком и номером поручения
  появляется, когда у персонажа можно взять/сдать задание (Кот — поручение 1, Кузнец — 2,
  Марья — 3). Золотой пульсирует = действие доступно; **серый (потухший)** = задание уже
  взято и выполняется — идти пока не нужно; после выполнения иконка исчезает вовсе.
- **Карточки выбора стези больше не пустые**: раньше прозрачные кнопки перекрывали рисунок
  и оставляли тёмные квадраты. Теперь каждая карточка рисуется целиком сама: эмблема
  оружия (булава+щит / лук с тетивой / посох с искрой), название, описание и подсказка
  клавиши [1]/[2]/[3]; рамка подсвечивается при наведении/нажатии.
- Метка версии обновлена до v0.21 (заставка и YavLaunch_error.log).

## Что нового в v0.20 (исправление «иероглифов» в строке управления)
- Все шрифты окна принудительно создаются с кириллическим набором символов
  (EASTEUROPE_CHARSET + ClearType) — нижняя строка подсказок больше не отображается
  «иероглифами» даже на системах с нестандартной локалью.
- Текст строки управления переписан корректно: ЛКМ — идти по прямой | E — говорить/брать |
  Shift+ЛКМ — диагональ лесенкой | Tab — сумка | I — зелье | 1–4 — умения.
- Метка версии в окне и в YavLaunch_error.log обновлена до v0.20.
- Сохранены все прежние исправления: единая система координат карта↔экран, клик мышкой
  точно под курсор (Г-образный маршрут), мини-карта справа сверху, иконки профессий,
  LAN co-op через UDP (второе окно видит героя с ником).

## Что нового в v0.19 (исправление отрисовки карты + мини-карта + иконки стезей)
- **Исправлена отрисовка мира**: после добавления большой карты объекты «разбежались» —
  все координаты деревни (избы, дуб, колодец, кот, кузнец, Марья, роща) приведены к единой
  системе мировых координат со смещением центра деревни; сетка движения совпадает с объектами.
- **Мини-карта** в правом верхнем углу: видна деревня, роща, границы мира, позиция героя
  (белая точка) и рамка текущего окна обзора.
- **Экран выбора стези**: вместо пустых квадратов — рисованные эмблемы профессий:
  Воин — булава со щитом, Лучник — лук со стрелой, Волхв — посох с искрами.
- Стабильность: исправлено переполнение буфера в обработчике ошибок (YavLaunch_error.log).

## Что было в v0.17 (большой мир + Г-образное движение)
- Мир 2048x1536: локация НЕ ограничена окном — камера следует за героем, при подходе
  к краю экрана происходит смещение обзора и отрисовка окрестностей (лес/поля).
- Деревня детально рисуется только в своей зоне; за её краями — опушка Тёмной рощи.
- Диагональный клик мыши превращается в L-образный маршрут из двух прямых участков
  под прямым углом (сначала более длинная ось); траектория показана пунктиром с углом.
- Сетка движения поверх всей карты; прежние фичи v0.16 сохранены (иконки, подсказки, сетка).

## Сохранено из прежних версий
- Окно 1024×768; создание героя — только ввод имени (вы начинаете молодцем);
- полный квест-цикл: жёлуди под дубом → Кот Учёный выдаёт руду и полотно сразу →
  Кузнец Терентий (булава/лук/посох) → Марья Искусница (доспех/мантия) →
  выбор стези Воин/Лучник/Волхв (клик или клавиши 1/2/3);
- всплывающие уведомления о выполнении поручений (5 сек);
- панель героя слева сверху (имя, уровень, HP, мана), фокус-окно сверху по центру,
  диалог справа с переносом текста, бар умений снизу по центру (клавиши 1–4,
  включая кнопку сбора ресурсов);
- инвентарь (Tab): экипировка кликом/двойным кликом, отображение надетого;
- стабильность v0.12–v0.15: устранены вылеты 0xC0000005 (безопасный формат строк,
  лимит повторов ошибки, лог `YavLaunch_error.log`).

## Управление
| Клавиша / действие | Что делает |
|---|---|
| ЛКМ по земле | Идти по прямой к точке (привязка к оси, видна траектория) |
| E | Говорить с NPC / подобрать жёлудь / собрать ресурс |
| 1–4 (или клик по баре) | Умения, слот 4 — сбор ресурсов |
| Tab | Инвентарь (клик по предмету — надеть/снять, зелье — выпить) |
| Наведение мыши на предмет | Подсказка о предмете |
| Esc | Закрыть диалог → закрыть сумку → выйти в меню |
| Enter | Подтвердить на экранах меню |
