# ЯВЬ: Забытые Былины — тестовая сборка v0.2 (Windows)

## Что нового в этой версии
1. **Реалтайм-сохранение.** Профиль (`YavLaunch_profile.json` рядом с exe)
   перезаписывается мгновенно при каждом значимом действии: выбор героя,
   ввод имени, вход в мир, ходьба (не чаще раза в 2 сек), подбор желудей,
   шаги квеста, выход из игры. Запись атомарная (temp + replace) — профиль
   не повредится даже при падении процесса. В HUD появляется метка
   «● сохранено».
2. **Экран «Продолжить игру».** Если рядом с exe найден сохранённый профиль,
   после кнопки «НАЧАТЬ ИГРУ» предлагается:
   - ПРОДОЛЖИТЬ ИГРУ — герой и прогресс загружаются из файла БД;
   - НОВЫЙ ГЕРОЙ — пересоздать персонажа;
   - Назад.
3. **Переход в мир — деревня.** После выбора героя (или «Продолжить») вы
   попадаете в небольшую деревню:
   - **Дуб-кормилец** в центре поляны, под ним лежат жёлуди;
   - **Кот Учёный** (в очках, со свитком) стоит рядом у дуба — приветствует
     вас по имени и даёт первое задание;
   - две избы, колодец, частокол, дорога.

## Управление (в мире)
| Клавиши | Действие |
|---|---|
| Стрелки / WASD | Ходьба по деревне |
| E | Говорить с Котом (рядом с ним) / взять жёлудь (рядом с ним) |
| ЛКМ / E | Закрыть окно диалога |
| Esc | Вернуться в меню (профиль сохранён) |

## Квест «Первая былинушка»
1. Подойти к Коту Учёному и нажать E → он поприветствует вас.
2. Ещё раз E → выдаёт задание: собрать 3 жёлудя под дубом.
3. Собрать жёлуди (подойти + E). Счётчик виден в трекере задания сверху.
4. Вернуться к Коту → он завершает квест и заносит имя в летопись.

Прогресс квеста сохраняется в реальном времени: можно закрыть игру на любом
шаге и продолжить с того же места.

## Файл профиля (файловая БД)
```json
{
  "version": 2,
  "updatedAt": "2026-10-05T12:00:00",
  "nickname": "Макар",
  "classId": 0,
  "hp": 150,
  "hpMax": 150,
  "pos": { "x": 320, "y": 380 },
  "quest": { "step": 2, "acorns": 2, "catTalked": true }
}
```
Формат полностью совпадает с моделью состояния Unity-проекта
(`Assets/Scripts/Data`), чтобы позже заменить файловое хранилище на
серверную БД без изменения логики.

## Запуск
1. Распакуйте архив в любую папку.
2. Запустите `YavLaunch.exe`.
3. Если SmartScreen мешает: «Подробнее» → «Выполнить в любом случае».

Окно фиксированное: **640×480**.

## Сборка из исходников (Linux)
```bash
sudo apt-get install gcc-mingw-w64-x86-64
./Prototype/build_game.sh
```
Основной исходник прототипа: `Prototype/yav_game.c`.
Хостовый тест save/load roundtrip: `Prototype/test_logic.c`.
